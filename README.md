# SmaC - School Manager Claude

A landing page (first web page) for **SmaC**, a digital platform designed to help schools manage student registration, track school payments securely, and centralize data.

## What the page contains
- A header with a navigation menu (Home, Features, About us, Contacts) and a **Connexion** button
- Collapsible "About us" and "Contacts" sections
- A main section with the platform's presentation and two buttons: **S'inscrire maintenant** and **Découvrir**
- A call-to-action section: "Prêt à digitaliser votre école ?"
- A footer

## Technologies
- HTML5
- CSS3 (no JavaScript yet)

## What I practiced
- Page structure with `header`, `nav`, `section`, and `footer`
- Layout with Flexbox
- Styled buttons with hover and click effects
- The `details` / `summary` tags for collapsible content
